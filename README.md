Entry for the make.fun bounty [The One-Line Excuse an Agent Gives Its Human](https://make.fun/bounty/u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e).

`main.py` (Python 3.13, standard library only) writes a single line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is
set): the excuse an AI agent hands its human after missing a deadline — an
upload that timed out, a retry loop with exponential backoff, and a deadline
that refused to wait along with it. The line is 140 characters, inside the
competition's 1–160 character gate.

Run the contract test with:

```
python3 test_entry.py
```
